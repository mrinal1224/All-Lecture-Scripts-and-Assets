### Question 1: What does the `querySelector` method do in JavaScript?

**Options:**

A) Creates a new HTML element.

B) Returns the first element that matches a specified CSS selector(s) in the document.

C) Returns all elements in the document that match a specified CSS selector(s) as an array.

D) Sends a query to the server based on the specified selector.

**Correct Answer:** B) Returns the first element that matches a specified CSS selector(s) in the document.

### Question 2: Which method is used to select all elements that match a specified CSS selector(s) in JavaScript?

**Options:**

A) `getElementById`

B) `querySelector`

C) `querySelectorAll`

D) `getElementsByClassName`

**Correct Answer:** C) `querySelectorAll`

### Question 3: What type of object does `querySelectorAll` return?

**Options:**

A) An array of HTMLElements.

B) A single HTMLElement.

C) A NodeList object containing all elements that match the specified group of selectors.

D) An HTMLCollection object containing all elements that match the specified group of selectors.

**Correct Answer:** C) A NodeList object containing all elements that match the specified group of selectors.

### Question 4: How do you set a new attribute for an HTML element in JavaScript?

**Options:**

A) `setAttribute('class', 'newClass');`

B) `getAttribute('class', 'newClass');`

C) `newAttribute('class', 'newClass');`

D) `updateAttribute('class', 'newClass');`

**Correct Answer:** A) `setAttribute('class', 'newClass');`

### Question 5: Which of the following is true about the event object in JavaScript?

**Options:**

A) It is used to get the current value of a CSS property.

B) It is passed to event handlers to provide properties and methods related to the event that occurred.

C) It cannot be used with user-defined functions.

D) It only contains information about keyboard events.

**Correct Answer:** B) It is passed to event handlers to provide properties and methods related to the event that occurred.
