### Detailed Reframing of "Implementing JSON Web Token (JWT) Authentication in Express"

#### Problem Statement
The goal is to implement JWT-based authentication within an Express.js application. The application should manage two routes: `/login` for user authentication and `/secret` for protected content access. Users log in by providing credentials, and on successful authentication, they receive a JWT. This token is then used to access the protected route.

#### Requirements
1. **Express.js Setup**: The application should use the Express.js framework.
2. **JWT Implementation**: Use the `jsonwebtoken` library for generating and verifying tokens.
3. **Routes**:
   - `/login` (POST): Accepts credentials (`username` and `password`) and returns a JWT on successful authentication.
   - `/secret` (GET): Requires a valid JWT in the `Authorization` header to access.

#### Code Stub

```javascript
  // Implementation for login

```

#### Solution Approach
1. **Login Route**:
   - Check if the `username` and `password` provided match the preset credentials ("admin" and "password").
   - If they match, generate a JWT with the username as payload and a secret key for signing.
   - Respond with the JWT.
   - If they do not match, respond with an error.

2. **Secret Route**:
   - Retrieve the JWT from the `Authorization` header.
   - Verify the JWT using the same secret key used for signing.
   - If the token is valid, display a welcome message with the username.
   - If invalid, respond with an error.

#### Complete Solution
```javascript
app.post('/login', (req, res) => {
  const { username, password } = req.body;
  if (username === 'admin' && password === 'password') {
    const token = jwt.sign({ username: 'admin' }, 'secretKey');
    res.json({ token });
  } else {
    res.status(401).json({ message: 'Invalid credentials' });
  }
});

app.get('/secret', (req, res) => {
  const authHeader = req.headers.authorization;
  if (authHeader) {
    const token = authHeader.split(' ')[1];
    jwt.verify(token, 'secretKey', (err, user) => {
      if (err) {
        return res.sendStatus(403);
      }
      res.send(`Welcome to the secret area, ${user.username}!`);
    });
  } else {
    res.sendStatus(401);
  }
});
```

#### Test Cases
1. **Login Route**:
   - **Test Input**: `{ username: "admin", password: "password" }`
   - **Expected Output**: JWT token response.
   - **Test Input**: `{ username: "user", password: "pass" }`
   - **Expected Output**: `401 Unauthorized` with "Invalid credentials".

2. **Secret Route**:
   - **Test Input**: Valid JWT in the Authorization header.
   - **Expected Output**: "Welcome to the secret area, admin!".
   - **Test Input**: Invalid or no JWT in the Authorization header.
   - **Expected Output**: `401 Unauthorized`.
