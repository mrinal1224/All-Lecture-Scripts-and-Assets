
**Title:** Implementing a Visit Counter in Express

**Problem Description:** 

You are tasked to implement a simple visit counter in an Express application. The application has one route: `/visit`.

The `/visit` route should accept a GET request. If the request contains a cookie named `visitCount`, it should increment the value of this cookie by 1. If the request does not contain this cookie, it should set it to 1. In both cases, it should respond with the message "This is your visit number [visitCount]".

**Code Stub:**

```javascript
const express = require('express');
const cookieParser = require('cookie-parser');

const app = express();
app.use(cookieParser());

app.get('/visit', (req, res) => {
  // Your code goes here
});

app.listen(3000, () => console.log('Server started on port 3000'));
```

**Solution:**

```javascript
app.get('/visit', (req, res) => {
  let visitCount = req.cookies.visitCount;
  if (visitCount) {
    visitCount = Number(visitCount) + 1;
  } else {
    visitCount = 1;
  }
  res.cookie('visitCount', visitCount);
  res.send(`This is your visit number ${visitCount}`);
});
```

Note: This solution assumes that the 'express' and 'cookie-parser' modules are installed in your project. If not, you can install them using `npm install express cookie-parser`.
