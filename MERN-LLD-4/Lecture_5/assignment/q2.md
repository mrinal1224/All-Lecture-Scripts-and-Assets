
**Question 2**

**Title:** Implementing Post-save Hook in Mongoose for Movie Model

**Problem Description:** 

You are tasked to implement a post-save hook in Mongoose for the Movie model. 

The post-save hook should log a message to the console stating "Movie [movie title] has been saved" every time a movie is saved to the database.

**Code Stub:**

```javascript
const mongoose = require('mongoose');

mongoose.connect('mongodb://localhost:27017/myapp', { useNewUrlParser: true, useUnifiedTopology: true });

const Movie = mongoose.model('Movie', new mongoose.Schema({
  title: { type: String, required: true },
  description: { type: String, required: true },
  duration: { type: Number, required: true },
  genre: { type: String, required: true },
  language: { type: String, required: true },
  releaseDate: { type: Date, required: true },
  poster: { type: String, required: true }
}));

// Your code goes here
```

**Solution:**

```javascript
Movie.schema.post('save', function(doc) {
  console.log(`Movie ${doc.title} has been saved`);
});
```

Note: These solutions assume that the 'mongoose' module is installed in your project. If not, you can install it using `npm install mongoose`. Also, make sure to replace 'mongodb://localhost:27017/myapp' with your actual MongoDB connection string.
