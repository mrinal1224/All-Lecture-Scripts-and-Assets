**Question 1: CSS Cascading and Specificity**

Which of the following factors determines the specificity of a CSS selector?

a. Position in the stylesheet  
b. Number of properties in the rule  
c. Presence of !important  
d. Combination of selector types and values  

**Correct Answer: d) Combination of selector types and values**

---

**Question 2: CSS Cascading and Specificity**

In the CSS specificity hierarchy, which selector has the highest specificity?

a. Class selector  
b. ID selector  
c. Element selector  
d. Universal selector  

**Correct Answer: b) ID selector**

**Question 5: CSS Cascading and Specificity**

What happens if two conflicting CSS rules have the same specificity?

a. The rule defined later in the stylesheet takes precedence  
b. The rule with the !important declaration takes precedence  
c. The browser applies both rules, merging their styles  
d. The browser selects the rule with the highest specificity  

**Correct Answer: a) The rule defined later in the stylesheet takes precedence**
