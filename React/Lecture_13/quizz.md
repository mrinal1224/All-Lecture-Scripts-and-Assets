## Q Which lifecycle method is invoked immediately after a component is mounted?

A) componentDidMount()

B) componentWillMount()

C) componentWillUnmount()

D) componentDidUpdate()

Correct Answer:
A) componentDidMount()

### Q In a React class-based component, which lifecycle method is called before a component receives new props?

A) componentWillReceiveProps()

B) componentDidUpdate()

C) componentWillUpdate()

D) componentWillUnmount()

Correct Answer:
C) componentWillUpdate()



### Q Which of the following statements about Pure components and re-rendering in React is true?

A) Pure components always re-render when their parent component re-renders.
B) Pure components only re-render when their props or state change.
C) Pure components re-render every time any component in the application updates.
D) Pure components re-render only if there is a change in the global state.

Correct Answer: B) Pure components only re-render when their props or state change.
