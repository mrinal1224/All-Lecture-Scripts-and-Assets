Question 1: What does the CSS Box Model consist of?

A) Margin, Padding, Content, Border
B) Margin, Padding, Text, Border
C) Border, Content, Float, Padding
D) Margin, Float, Width, Padding

Correct Answer: A) Margin, Padding, Content, Border

---

Question 2: Which CSS property is used to set the space between an element's border and its content?

A) margin
B) padding
C) border-spacing
D) spacing

Correct Answer: B) padding

---

Question 3: In CSS, which positioning property is used to place an element relative to its normal position?

A) static
B) relative
C) absolute
D) fixed

Correct Answer: B) relative

---

Question 4: What is the default value for the position property in CSS?

A) static
B) relative
C) absolute
D) fixed

Correct Answer: A) static
