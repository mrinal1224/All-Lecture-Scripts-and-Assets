

**Question 1:**
*Which CSS selector is used to select all elements with the class "highlight"?*

A. `#highlight`

B. `.highlight`

C. *`highlight`*

D. `*highlight*`

**Answer: B. `.highlight`**

---

**Question 2:**
*What does the CSS selector "ul > li" target?*

A. All `<ul>` elements inside a `<li>`.

B. All `<li>` elements inside a `<ul>`.

C. Only the first `<li>` inside any unordered list (`<ul>`).

D. All list items regardless of their parent.

**Answer: B. All `<li>` elements inside a `<ul>`**

---


**Question 3:**
*What does the CSS selector "input[type='text']" select?*

A. All input elements.

B. All text elements.

C. All elements with the attribute "text".

D. Only input elements of type "text".

**Answer: D. Only input elements of type "text"**
