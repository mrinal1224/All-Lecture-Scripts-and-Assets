**Question 1:**
Which HTML tag is used to create an ordered list?

A) \<ul>\
B) \<li>\
C) \<ol>\
D) \<dl>

**Correct Answer:** C) \<ol>

---

**Question 2:**
In an HTML table, what does the \<th> tag represent?

A) Table header\
B) Table data\
C) Table row\
D) Table column

**Correct Answer:** A) Table header

---

**Question 3:**
Which HTML tag is used to create a drop-down list in a form?

A) \<input type="dropdown">\
B) \<select>\
C) \<list>\
D) \<dropdown>

**Correct Answer:** B) \<select>

---

**Question 4:**
What is the purpose of the \<ul> tag in HTML?

A) Unordered list\
B) Underline text\
C) Upper left alignment\
D) Universal link

**Correct Answer:** A) Unordered list

---

**Question 5:**
Which HTML input type is used for collecting numeric input?

A) \<input type="number">\
B) \<input type="text">\
C) \<input type="numeric">\
D) \<input type="integer">

**Correct Answer:** A) \<input type="number">
