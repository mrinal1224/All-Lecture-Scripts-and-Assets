Question 1: What does the CSS Box Model consist of?

A) Margin, Padding, Content, Border
B) Margin, Padding, Text, Border
C) Border, Content, Float, Padding
D) Margin, Float, Width, Padding

Correct Answer: A) Margin, Padding, Content, Border

---

Question 2: Which CSS property is used to set the space between an element's border and its content?

A) margin
B) padding
C) border-spacing
D) spacing

Correct Answer: B) padding

**Question 3: CSS Units**

What does the 'em' unit in CSS represent?

a. Pixels  
b. Percentage of the viewport width  
c. Font-size of the element's parent  
d. Centimeters  

**Correct Answer: c) Font-size of the element's parent**

---

**Question 4: CSS Units**

Which CSS unit is commonly used for responsive design and is based on the viewport size?

a. px (pixels)  
b. vw (viewport width)  
c. % (percentage)  
d. em (em units)  

**Correct Answer: b) vw (viewport width)**
