**Question 1:**
Which CSS property is used to establish a flex container?

a) `display: inline;`  
b) `display: flexbox;`  
c) `flex-direction: row;`  
d) `display: flex;`  

**Correct Answer: d) `display: flex;`**

---

**Question 2:**
What is the default value for the `flex-direction` property in a flex container?

a) `column`  
b) `row`  
c) `row-reverse`  
d) `column-reverse`  

**Correct Answer: b) `row`**

---

**Question 3:**
In a flex container, what does the `align-items` property control?

a) The alignment of flex items along the main axis  
b) The alignment of flex items along the cross axis  
c) The order of flex items  
d) The flexibility of flex items  

**Correct Answer: b) The alignment of flex items along the cross axis**

---

**Question 4:**
Which media query is used to apply styles only when the viewport width is 600 pixels or less?

a) `@media (max-width: 600px)`  
b) `@media (min-width: 600px)`  
c) `@media (width <= 600px)`  
d) `@media (max-width <= 600px)`  

**Correct Answer: a) `@media (max-width: 600px)`**
