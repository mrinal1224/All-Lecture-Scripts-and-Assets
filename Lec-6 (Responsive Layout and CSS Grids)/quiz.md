**Question 1:**
What property is used to define the size of columns and rows in a CSS Grid?

A. `grid-gap`  
B. `grid-size`  
C. `grid-template`  
D. `grid-column`

**Correct Answer:** C. `grid-template`

---

**Question 2:**
Which CSS property is used to place an item in a specific cell within the CSS Grid?

A. `grid-position`  
B. `grid-row`  
C. `grid-cell`  
D. `grid-area`

**Correct Answer:** D. `grid-area`

---

**Question 3:**
What is the purpose of the CSS property `justify-items` in the context of CSS Grid?

A. Aligns grid items along the block axis  
B. Justifies content inside grid items along the inline axis  
C. Adjusts the space between grid items  
D. Sets the size of the grid columns

**Correct Answer:** B. Justifies content inside grid items along the inline axis

---

**Question 4:**
Which CSS property is used to create a gap between columns and rows in a CSS Grid?

A. `grid-gap`  
B. `grid-space`  
C. `grid-margin`  
D. `grid-padding`

**Correct Answer:** A. `grid-gap`

---

**Question 5:**
What value should be used for the CSS property `grid-auto-flow` to automatically place items in the grid without specifying a placement?

A. `auto`  
B. `flow`  
C. `grid`  
D. `dense`

**Correct Answer:** C. `grid`
